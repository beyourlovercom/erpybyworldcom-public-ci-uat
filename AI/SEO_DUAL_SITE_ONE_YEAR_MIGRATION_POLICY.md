# YBY SEO Dual-Site / One-Year Migration Policy

Effective: 2026-09-18

## Operating model

For the current transition period, both domains may remain live:

- Legacy: `yby-irrigation.com` / `www.yby-irrigation.com`
- New operating site: `ybyirrigation.com`

The legacy site is managed by a separate SEO provider and is read-only from this program. Do not modify its content, DNS, Cloudflare, redirects, canonicals, hosting, or infrastructure during the coexistence period.

## Data usage

Historical and ongoing data from the legacy site may be used as supporting evidence for the new site, including:

- Google Ads keyword / search-term / conversion evidence
- Google Search Console query / page / impression / click / CTR / average-position evidence
- proven commercial-intent terms
- historical landing-page and content performance

Legacy data is evidence, not the execution target. New SEO work orders, content, landing pages, internal links, and measurement should operate on `ybyirrigation.com`.

## Planned migration horizon

Target horizon: approximately 12 months from 2026-09-18, subject to a fresh owner approval and coordination with the external SEO provider.

At final migration:
1. freeze both sites' latest GSC / Ads / URL inventories;
2. build a complete old-URL → new-URL mapping;
3. validate each new destination before cutover;
4. implement permanent redirects from the legacy URLs to their corresponding new URLs;
5. update canonicals / sitemaps / internal references as needed;
6. monitor GSC migration signals and crawl/indexing changes;
7. retain rollback evidence and migration manifests.

Do not perform the final redirect/cutover automatically based only on elapsed time. It requires an explicit migration gate.

## Measurement rule

During coexistence, report legacy and new-domain metrics separately. Use legacy performance as historical/reference evidence and new-domain performance as the KPI target. Do not merge the two into one metric series in a way that hides which domain earned the result.
